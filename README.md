# 个人重建系统

在浏览器里记录每天的锻炼和学习，并按设计稿结算属性、积分和等级。数据只存在这台浏览器的本地存储里。

## 本地打开

在仓库根目录执行：

```bash
npm test
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:4173 。

## 第一版有什么

- 录入身高、体重、睡眠、每周锻炼和可选自测。身高体重只显示筛查带。
- 自己添加和停用学习科目。没有预置清单。同时重点最多 5 门。
- 记录力量、有氧、灵活、平地步行和学习分钟，结算有效分钟与六项属性。
- 每天三条任务。完成给积分和小幅属性；跳过不扣分。有伤病标记时改为过滤后的调理三条，并写明不是医疗建议。
- 面板显示六项属性、恢复、积分、等级。
- 衰减按已接受的规则执行：有宽限、有地板，假期最多 14 天暂停计数。
- 一门课在任意 7 天内有 5 天有效学习不少于 15 分钟时，升到 1 阶，称号为「科目初学者」，并显示一枚「科目·开课」。

## 第一版没做什么

- 2 阶到 6 阶，以及提取、讲解、真实使用、提纲这些进阶条件。
- 徽章柜、称号休眠、佩戴切换、积分重抽、升阶以外的徽章。
- 每周三条任务、月度校准、补记、连续守约、排行、饮食、社交。
- 账号和多设备同步。
